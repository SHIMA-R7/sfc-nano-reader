# 実験データ

すべてカービィ スーパーデラックス（SA-1）またはスターフォックス（GSU）の実測。
判定は「既知の正解ROMとバイト単位で一致するか」。

| ファイル | 内容 | 試行数 |
|---|---|---|
| `voltage_sweep.csv` | GSU（スターフォックス）の電圧掃引 5.00-4.50V | 60 |
| `clock_sweep.csv` | SA-1のクロック掃引（初回・各5回） | 35 |
| `clock_confirm.csv` | 同上を3条件×20回で取り直し | 60 |
| `wake_sweep.csv` | 起動読みの要素分解 5条件×20回 | 100 |
| `sa1_voltage.csv` | SA-1の電圧掃引 5.00-4.50V ×20回 | 120 |
| `wake_decay.csv` | 起動読みの持続時間 0/10/30/60/180秒 ×15回 | 75 |
| `proxy_check.csv` | 1バンク判定と全64バンク読みの突き合わせ | 20 |
| `baseline40.csv` | 基準条件の追試 | 40 |

`power_log.csv`（0.5秒刻みの電流記録）はリポジトリ直下にある。

## 読むときの注意

**`match` 列は約10%の上振れを含む。** `proxy_check.csv` で検証したところ、
1バンク判定は全64バンク読みと18/20で一致し、外れた2件はどちらも楽観側
（判定は成功・全体は失敗）だった。条件間の比較は同じ偏りを受けるので有効だが、
絶対値は割り引くこと。
